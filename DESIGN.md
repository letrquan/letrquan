# Design: letrquan GitHub Profile

## Direction

Text only. The profile is a short introduction, a list of three project links, and a contact line, rendered entirely by GitHub's own Markdown styles. There are no images, badges, tables, or custom assets.

## Structure

1. `# Zain` — name as the page heading.
2. One paragraph: role, what gets built, and the two main languages.
3. `**Projects**` followed by a three-item list. Each item is `[Name](repo) — one-line description`.
4. One closing line on how to get in touch.

## Rules

- Say each thing once. If a line repeats what another line already says, remove it.
- Every project description must trace to the linked repository's own README. No metrics, model names, version numbers, or adoption claims.
- Stay within GitHub-flavored Markdown. No inline HTML, no hosted images, no badge services.
- Keep it short enough to read without scrolling on a laptop.
