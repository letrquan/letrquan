## A little about me

- I am building **Book**, a provider-agnostic AI coding agent with a rich terminal UI, persistent sessions, memory, MCP support, and managed agents.
- I enjoy turning everyday friction into focused products, from caption-aware video tools to system-wide voice typing.
- I care about the details behind the demo: accessibility, graceful failure modes, tests, and interfaces that stay clear as systems grow.
- I work comfortably across web, terminal, browser-extension, and Windows desktop environments.
