# Zain

Software engineer and product builder. I make developer tools — AI coding agents, browser utilities, and Windows desktop apps — mostly in TypeScript and Rust. Apparently, computers needed more of my attention, not less.

## Things I’ve built (instead of closing my tabs)

- [Book CLI](https://github.com/letrquan/book) — provider-agnostic AI coding agent for the terminal. I built an AI coworker to write code; now I have code to review.
- [Better Picture](https://github.com/letrquan/better-picture) — caption-aware floating mini-player for Chrome and Edge, so your video can escape its tab without losing the plot.
- [V Voice](https://github.com/letrquan/v-voice-claude) — floating Whisper dictation widget for Windows. Talk to your computer; pretend this was always the plan.

Open to collaboration — an issue on any repository is the fastest way to reach me. Carrier pigeons are not currently supported.
